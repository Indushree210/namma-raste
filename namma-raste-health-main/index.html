Android Kotlin Project

NAMMA RASTE HEALTH

This project is a complete Android Studio Kotlin Project. It is not a web application.

To use this code:

  1. Download the source files from the Settings > Export menu.
  2. Open the folder in Android Studio (Iguana or newer).
  3. Update YOUR_GEMINI_API_KEY in strings.xml and GeminiService.kt.
  4. Add your google-services.json from Firebase Console.

Tech Stack: Jetpack Compose, Hilt, Firebase, Gemini 1.5 Flash Vision, Google Maps SDK.
